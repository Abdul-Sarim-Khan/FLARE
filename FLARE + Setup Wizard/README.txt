
The "setup_maker" directory contains what is used for making a setup exe file, it requires INOSETUP to run. I included this directory as it was part of the "source code" as well.

The "compressed_exe" directory contains the setup exe files that you can just run, it will auto install everything except for python and npcap, which it does tell you on the screen whilst installing.

The "attack_script" directory contains scripts that simulate/perform attacks on a computer to verify the software is detecting and classifying the attacks correctly.

The "extracted" directory contains a server and client directory, these would be the files that get extracted onto a computer when the setup exe files are ran.



Further READMEs can be found in each directory as needed.
